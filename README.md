# 🌱 Smart Agriculture System

An intelligent agriculture application that uses machine learning to support farmers in making better agricultural decisions.

The system provides features related to crop yield prediction, soil quality analysis, fertilizer recommendations, plant disease detection, and weather-based crop suggestions.

## 🚀 Features

- 🌾 **Crop Yield Prediction** — Predict crop yield using the available model and input data.
- 🧪 **Soil Quality Analysis** — Analyze soil-related information to support better farming decisions.
- 🌿 **Fertilizer Recommendation** — Provide fertilizer recommendations based on supported inputs.
- 🍃 **Plant Disease Detection** — Detect plant diseases using a TensorFlow Lite model.
- 🌦️ **Weather-Based Crop Suggestions** — Suggest suitable crops using the weather information supported by the application.

## 🛠️ Technologies Used

- **Python** — Core programming language
- **Flask** — Web application framework
- **TensorFlow Lite** — Lightweight machine learning model inference
- **Machine Learning** — Prediction and recommendation features
- **HTML, CSS and JavaScript** — Frontend technologies, if included in the project

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/pranshusingh07/Smart-Agriculture-System-.git
```

### 2. Open the Project Folder

```bash
cd Smart-Agriculture-System-
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

For Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 5. Install Dependencies

If your project contains a `requirements.txt` file, run:

```bash
pip install -r requirements.txt
```

If the file does not exist, create it with the actual dependencies required by your project.

### 6. Run the Application

If `api/index.py` is the Flask entry point, run:

```bash
python api/index.py
```

Open the application in your browser:

```text
http://127.0.0.1:5000
```

*Note: This assumes your Flask application runs on port 5000.*
